# Reliance Lens — AI Assurance Workbench

**Research prototype · 2026**

**Live demo:** https://<username>.github.io/reliance-lens-ai-assurance/

Reliance Lens is a framework for examining whether apparently independent safeguards, evaluations, or interventions provide genuinely independent assurance—or remain coupled through shared assumptions, representations, infrastructure, people, signals, or decision pathways.

This prototype applies that question to AI assurance.

## Core question

> When multiple safeguards appear to provide defence in depth, what evidence establishes that they would not fail together?

The Workbench structures the analysis as:

**Claim → Function → Reliance → Coupling → Independence → Test → Evidence → Finding**

The purpose is not simply to determine whether an AI system passes an individual evaluation. It is to examine whether the **basis for confidence** is itself robust.

## What the prototype demonstrates

The Workbench allows a researcher to:

* state an assurance claim;
* identify the function that must actually be protected;
* map safeguards to their dependencies;
* identify potential common-mode coupling;
* formulate discriminating tests;
* distinguish evidence from inference;
* generate a structured assurance finding.

## Scope

This is a **research and evaluation prototype**, not an audit, certification, compliance determination, security assessment, or empirical claim about any particular AI system.

A production evaluation would require a prespecified protocol, actual model runs, retained evidence, replication, adjudication, and uncertainty analysis.

## Relationship to Reliance Lens

This prototype is an application of the broader **Reliance Lens** research programme, which examines dependence, coupling, functional equivalence, and the conditions under which apparently different interventions may fail together.

The broader research architecture is maintained separately by the author.
