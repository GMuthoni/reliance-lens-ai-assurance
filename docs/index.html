6. Discriminating tests

Good assurance tests should separate competing explanations rather than simply accumulate more evidence for the existing story.

Test Question What would change confidence?
Common-mode failure test What happens when the shared dependency is deliberately perturbed? Independent controls continue detecting the failure.
Blind-spot test Can a novel failure escape every existing detection pathway? A control detects the failure without relying on the existing taxonomy.
Assumption inversion What if a central assumption used by several evaluations is false? At least one evaluation remains informative.
Evidence-independence test Are several reassuring findings actually derived from the same data, model behavior, evaluator, or deployment assumption? Evidence sources remain informative when the common source degrades.
Adversarial authority test Does false authority, urgency, or instruction hierarchy change protected behavior? System boundaries remain stable under matched pressure.
